# Infinity Holdings Limited - Corporate Website

Infinity Holdings Limited is a global diversified holding company building enduring value across seven industries: Real Estate, Infrastructure, Investments, Hospitality, Technology, Manufacturing, and Renewable Energy.

This repository contains the front-end source code for the corporate website.

## Project Structure

- `index.html` - Homepage
- `about.html` - About Us
- `sectors.html` - Business Sectors
- `projects.html` - Featured Projects
- `innovation.html` - Innovation
- `sustainability.html` - Sustainability
- `contact.html` - Contact Us
- `/css` - Stylesheets
- `/js` - JavaScript files
- `/assets` - Images, icons, and other static assets
- `/reference` - Reference materials

## Technology Stack

- HTML5
- CSS3 (Custom styling with modern layouts like Flexbox/Grid)
- Vanilla JavaScript
- Font: Fraunces & Inter (Google Fonts)
- Scroll library: Lenis

## Features

- Fully responsive design
- Parallax scrolling effects
- Interactive fullscreen navigation menu
- Clean, modern "Designed for Life" aesthetics

## Setup & Running

This is a static website. You can run it by opening `index.html` in any modern web browser, or by using a local development server.

For example, using Python:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
